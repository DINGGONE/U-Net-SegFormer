## 第 4 步：装 PyTorch（想训练模型才需要）

前面 3 步都是"传统方法"，不训练。**真正跑深度学习（U-Net / SegFormer）才需要 PyTorch。**

### 4.1 先确认你的显卡在

```bat
nvidia-smi
```

应该看到 `NVIDIA GeForce RTX 2060`、显存 `6144MiB` 左右。看到就说明能用 GPU 训练。

### 4.2 装（约 2~3 GB，需要耐心）

```bat
"C:\ProgramData\anaconda3\python.exe" -m pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cu121
```

⚠️ 我实测你这台机器的外网只有 **约 120 KB/s**，2~3 GB 要下 **5~7 小时**，还容易断。
**三个加快的办法，按推荐顺序：**

| 办法 | 怎么做 | 效果 |
|---|---|---|
| ① 用国内镜像 | `-i https://pypi.tuna.tsinghua.edu.cn/simple` 替换 `--index-url ...` | 通常能到 2~10 MB/s |
| ② 换网络 | 手机热点 / 公司网络试一次，先测 10 秒能不能到 1 MB/s | 视情况 |
| ③ 离线包 | 在快的机器上下 `torch-2.4.1+cu121-cp39-cp39-win_amd64.whl`，拷过来 `pip install 文件路径` | 一劳永逸 |

装完验证（**必须出现 True**）：

```bat
"C:\ProgramData\anaconda3\python.exe" -c "import torch;print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

再装其余依赖：

```bat
"C:\ProgramData\anaconda3\python.exe" -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 装不上也别慌：**不装也能完成第 1~3 步的所有事情**，只是不能训练。

### 4.3 ⚠️ 最容易搞错的一件事：pip 默认装的是「CPU 版」

这是新手最容易卡住的地方，务必分清：

| | CPU 版 | CUDA 版（显卡版） |
|---|---|---|
| 体积 | 约 200 MB | 约 2.4 GB |
| 从哪装 | `pip install torch`（PyPI 默认） | 必须指定 CUDA 源或本地 wheel |
| `torch.cuda.is_available()` | **False** | True |
| `torch.version.cuda` | **None** | `'12.1'` |
| 训练速度 | 慢 10~50 倍 | 用满显卡 |
| 适合 | 学流程、跑通代码、小数据试验 | 真正训练模型 |

**判断自己装的是哪个**（一条命令）：

```bat
"C:\ProgramData\anaconda3\python.exe" -c "import torch;print('CUDA:', torch.version.cuda, '| 可用:', torch.cuda.is_available())"
```

- 输出 `CUDA: None | 可用: False` → 装的是 CPU 版，**这是正常的**，不是装坏了；
- 输出 `CUDA: 12.1 | 可用: True` → 显卡版，可以正式训练。

**从 CPU 版换成 CUDA 版**（不用卸载，直接覆盖安装）：

```bat
:: 官方源在国内经常只有几十 KB/s，2.4 GB 可能下一天
"C:\ProgramData\anaconda3\python.exe" -m pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cu121

:: 更快：走阿里云镜像 + 断点续传（断了重跑会接着下）
"C:\ProgramData\anaconda3\python.exe" scripts\get_torch_cuda.py
"C:\ProgramData\anaconda3\python.exe" scripts\get_torch_cuda.py --install
```

> 这个脚本是专门为"国内下 2.4 GB 老断"写的：支持断点续传、自动重试、实时显示速度。
> 可以挂着过夜，第二天 `--install` 装完就行。

## 第 7 步：用自己的影像（有影像没标注也能做）

### 7.1 先体检，别急着跑

```bat
"C:\ProgramData\anaconda3\python.exe" scripts\inspect_image.py --src D:\data\我的影像.tif
```

它会告诉你：尺寸、波段、位深、**坐标系和分辨率**、覆盖多少公顷、要切成几个瓦片、大概跑多久，
以及**能不能直接套模型**。最关键的一条是分辨率——和训练数据差太多（比如 10 m 的 Sentinel-2
配 0.3 m 航拍的权重），精度会崩，必须重新训练。

### 7.2 支持什么格式

| 能给 | 说明 |
|---|---|
| GeoTIFF（推荐） | 保留坐标系/分辨率，结果能直接拖进 QGIS 叠图，面积算得准 |
| PNG / JPG | 也能跑，但没有地理信息，比例尺和面积要靠 `--gsd` 手动给 |
| 3 波段 RGB | ✅ 标准输入 |
| 4 波段（含 NIR） | 会取前 3 个当 RGB；要用 NIR 得把 `in_channels` 改 4 并重训 |
| 8bit / 16bit | 都行，16bit 会**自动做 2%~98% 百分位拉伸**（不拉伸会全黑） |
| 任意尺寸 | 都行，滑窗自动切；太小（<512）会填充后推理，边缘不可信 |

### 7.3 跑推理出图

```bat
"C:\ProgramData\anaconda3\python.exe" scripts\predict.py ^
    --ckpt runs\loveda_unet_r34\best.pt ^
    --src D:\data\我的影像.tif --out-dir outputs\my_area --gsd 0.3 --poster
```

产出 5 个文件：`*_landcover.tif`（保留 CRS 的类别栅格）、`*_landcover.png`（彩色图）、
`*_landcover.json`（元信息）、`*_poster.png/pdf`（成果图）。

### 7.4 ⚠️ 最重要的一句话

**流程能跑通 ≠ 结果有意义。** 必须用"和你影像同类"的数据训练出的权重。
在合成数据上训 3 个 epoch 的权重拿去跑真实影像，输出就是一堆彩色噪点——这不是代码错，是模型没见过这种影像。

### 7.5 没有标注怎么办

| 情况 | 做法 |
|---|---|
| 有影像没标注 | 用 LoveDA/Potsdam 训好的权重直接推理（跨城一般能用，mIoU 掉 5~10 点） |
| 影像风格差异大（不同传感器/季节/分辨率） | 标 50~100 个图斑做**微调**（fine-tune），1~2 小时能显著提升 |
| 只要建筑 | 用 SpaceNet 训的权重，二分类更稳 |
| 完全没标注也要应急 | 用 GEE 的 NDVI/NDWI/NDBI 指数做规则分类，精度低但能出图 |

## 常见报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `'python' 不是内部或外部命令` | 微软商店占位符 | 用完整路径 `C:\ProgramData\anaconda3\python.exe` |
| `ModuleNotFoundError: No module named 'torch'` | 还没装 PyTorch | 第 4 步 |
| `AssertionError: Torch not compiled with CUDA enabled` | 装的是 **CPU 版** torch | 正常现象，见 §4.3；要显卡就换 CUDA 版 |
| `TypeError: 'numpy._DTypeMeta' object is not subscriptable` | opencv 4.8 与 numpy 1.21 不兼容 | `pip install opencv-python-headless==4.5.5.64` |
| `OMP: Error #15: Initializing libiomp5md.dll` | conda 的 MKL 与 torch 的 OpenMP 冲突 | 用本项目的脚本（`rsc/__init__.py` 已自动处理）；自己写脚本时先 `import rsc` |
| `TypeError: __init__() got an unexpected keyword argument 'border_mode'` | albumentations 版本差异 | 已修复（`data.py` 做了版本适配）；升级到最新代码即可 |
| `Cannot install segmentation-models-pytorch and timm` | smp 0.3.4 硬依赖 timm==0.9.7 | `pip install timm==0.9.7` |
| `ModuleNotFoundError: No module named 'numpy'` | 用的不是 conda 的 python | 确认路径里有 `anaconda3` |
| `UnicodeDecodeError` / 中文乱码 | 终端编码 | `chcp 65001` 后重跑 |
| 图片里中文变成方框 | 缺中文字体 | 装 SimHei / 微软雅黑（你机器已有，一般不会） |
| `CUDA out of memory` | 显存不够 | 降 `--batch-size` / `--crop-size` |
| `FileNotFoundError: data\loveda\train\images` | 没整理数据 | 跑 `prepare_loveda.py` |
| `pip` 下载卡 0% | 网络 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `RuntimeError: DataLoader worker` | Windows 多进程 | `--num-workers 0` |

## 名词小词典

| 词 | 一句话解释 |
|---|---|
| **像素级分割** | 给每个像素贴一个类别标签，不是在图上画框 |
| **mIoU** | 平均交并比，0~1，越大越好。0.5 左右算能看，0.7 算好 |
| **F1** | 精确率和召回率的调和平均，看"漏检和误检的平衡" |
| **OA** | 总体精度，就是"猜对了百分之多少的像素" |
| **epoch** | 把训练集完整看一遍叫 1 个 epoch |
| **batch** | 一次喂给显卡几张图。显存越小，batch 越小 |
| **GSD** | 地面分辨率，1 个像素代表多少米。LoveDA 是 0.3 m |
| **滑窗推理** | 大图切成 512×512 的小块分别预测，再拼回去 |
| **碎斑过滤** | 把面积过小的孤立图斑合并到周围，让图好看 |
| **模型权重 `.pt`** | 训练出来的"经验文件"，推理时加载它 |

## 一句话建议

**别一开始就想训出高精度。** 先让"数据 → 模型 → 图"这条线完整跑一遍（D1~D5），
再去调参（D6~D7）。90% 的新手卡在环境上，而不是算法上——所以第 1 步我做成了一键。
